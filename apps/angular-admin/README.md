# Angular Admin

Angular 17+ shell application for KYC platform administrators and compliance officers.

## Responsibilities

- Tenant management
- KYC case review and approval workflow
- User role and permission management
- Compliance reporting interface (embedded Vue micro-frontend)
- Real-time notifications via GraphQL subscriptions

## Getting Started

```bash
npm install
npm start
```

Application will be available at `http://localhost:4200`.
